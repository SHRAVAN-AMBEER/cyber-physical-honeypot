1. Project Overview

The EduCore Exam Vault Cyber-Physical Honeypot is deployed on a Raspberry Pi to simulate a secure institutional data center protecting digital exam scripts. It integrates real IoT hardware with a deceptive 4-page web portal to detect, log, and alert on unauthorized access in real time.

The system runs as two separate processes launched by start.sh: a Flask web server (unified_server.py) and a GPIO hardware controller (hardware_trap.py). They communicate via an IPC mechanism using a shared JSON flag at /tmp/honeypot_state.json, polled every 500ms.

Platform: Raspberry Pi 3B/4  |  Port: 8080  |  OS: Raspberry Pi OS Debian 12 Bookworm 64-bit  |  Language: Python 3.11+
2. System Architecture
2.1 Two-Process Design
Process File Role
Process 1 — Web Server unified_server.py Flask on port 8080. Serves all 4 trap pages. Handles all web logic, sends Telegram alerts, writes IPC alarm flag to shared JSON. Cannot access GPIO directly.
Process 2 — GPIO Owner hardware_trap.py Sole owner of all GPIO pins. Polls /tmp/honeypot_state.json every 500ms. Fires buzzer+LED when flag detected. Also monitors MC-38 for physical door breach independently.
2.2 IPC Mechanism (Web → GPIO)

The Flask web process cannot access GPIO hardware directly. Alarm requests are passed via a shared JSON flag file:

unified_server.py  writes  {"alarm_requested": true}  to  /tmp/honeypot_state.json
hardware_trap.py   polls file every 500ms
                   on flag detected: GPIO 18 (Buzzer) ON + GPIO 23 (LED) ON
                   resets flag to false after alarm
End-to-end latency: Physical alarm fires within <500ms of any web-triggered attack action.

4.2 GPIO Pin Mapping (BCM Numbering)

All GPIO numbers use BCM (Broadcom) scheme as required by the gpiozero library.

BCM GPIO Physical Pin Component Direction Behaviour
GPIO 4 Pin 7 DHT-11 Data Input Single-wire protocol. Read every 3s by sensor_hub.py using adafruit-circuitpython-dht.
GPIO 17 Pin 11 MC-38 Reed Switch Input Pull-up enabled. Normally HIGH (closed). Goes LOW when door opens → CRITICAL alarm fires immediately.
GPIO 18 Pin 12 Active Buzzer (+) Output HIGH = buzzer ON. Controlled exclusively by hardware_trap.py.
GPIO 23 Pin 16 Red LED (via 330Ω) Output HIGH = LED ON. Always fires together with GPIO 18 buzzer. Never triggered independently.
3.3V / 5V Pin 1, 2, 4 VCC supply Power DHT-11 → 3.3V  |  Active Buzzer → 5V
GND Pin 6, 9, 14 Common Ground Ground Shared ground for DHT-11, MC-38, Buzzer, LED
Alarm pair rule: GPIO 18 (Buzzer) and GPIO 23 (LED) always activate and deactivate together. They are controlled as a unit by hardware_trap.py.

5.6 Python Source Modules
File Process Role Key Libraries
unified_server.py Process 1 Main Flask application. Routes: GET / (dashboard), GET+POST /login (credential trap), GET /admin (admin panel trap), GET+POST /emergency (social engineering trap), GET /api/sensors (DHT-11 JSON), GET /api/events (security log JSON), POST /api/action (admin button trap). Sends Telegram on every interaction. Calls request_alarm() from sensor_hub for CRITICAL actions. flask, requests, python-dotenv, threading, json, datetime
hardware_trap.py Process 2 GPIO sole owner. Initializes: buzzer (GPIO 18), LED (GPIO 23), MC-38 switch (GPIO 17). Runs start_alarm_watcher() background thread that polls /tmp/honeypot_state.json every 500ms and fires GPIO alarm when alarm_requested is true. Also runs door monitor thread that watches MC-38 for physical breach. gpiozero, lgpio, json, time, threading
sensor_hub.py Process 1 DHT-11 interface module. Reads GPIO 4 every 3s, caches last valid reading. Provides get_sensor_data() for /api/sensors and request_alarm() which writes IPC flag to /tmp/honeypot_state.json. adafruit-circuitpython-dht, json, time, threading
decoy_alert.py Process 1 Telegram sender. send_telegram_alert(message) POSTs to Telegram Bot API. Loads BOT_TOKEN and CHAT_ID from .env via python-dotenv. requests, python-dotenv, os
start.sh Launcher Bash script. Starts hardware_trap.py first (GPIO ownership), then unified_server.py (web server). Both run as background processes. bash
